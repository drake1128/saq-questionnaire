術中操作教學

SAPIEN 3 Ultra Commander Delivery System

Edwards Lifesciences｜TAVI 術中操作 — 旋鈕、Markers、Alignment、Deployment 心智走訪
🏥 國立臺灣大學醫學院附設醫院新竹臺大分院　心臟血管中心
⚠️ 使用前請務必閱讀

本文件為術前預習用教學共筆，目的是建立術中名詞、組件、操作層次的對應關係，並非操作 SOP，不取代 IFU、廠商 Clinical Specialist (CS) 與 Proctor 的現場指導。

實際操作時，安全網優先順序為：Edwards CS > Proctor > IFU > 個人訓練 > 本共筆。任何與 IFU 衝突之敘述，以 IFU 為準。

📌 Take Home — CS 抵達前先記住這 5 點
  1. Sapien 3 Ultra 用的是 Commander delivery system，handle 上只有 2 個旋鈕 + 1 個鎖：Flex Wheel、Fine Adjustment Wheel、Balloon Lock。
  2. 「Alignment」在 S3 系統有 3 個不同層次的意思，不要混為一談。
  3. Fine Adjustment Wheel 只有在 Balloon Lock 鎖上之後才能轉。順序錯會壞 system。
  4. 抽出 system 前一定要 unflex，並確認 Flex Catheter tip 鎖回 Triple Marker — IFU 明列的 patient-safety caution。
  5. 「Flagchain」不是 Edwards 官方術語。等 CS 抵達時直接指著 system 確認你聽到的詞對應到哪個元件。
核心參考圖｜Edwards COMMANDER Delivery System（節錄自 Edwards SAPIEN 3 Ultra IFU, Figure 3）
以下章節提到的所有名詞 — Tapered Tip、Valve Alignment Markers、Center Marker、Triple Marker、Valve Crimp Section、Flex Catheter、Flex Indicator、Flush Port、Strain Relief、Edwards logo（E）、Fine Adjustment Wheel、Flex Wheel、Balloon Lock、Balloon Catheter、Guidewire Lumen、Balloon Inflation Port — 都可以對應回這張圖。
1Delivery System 三大組件

Edwards Commander delivery system 由外層 Flex Catheter（協助對位、追蹤、定位）與內層 Balloon Catheter（瓣膜壓接於其上）組成，前端為 tapered nose cone 以利通過 native valve。

SAPIEN 3 Ultra THV（Model 9750TFX）— 即「壓接於 Balloon Catheter 上」的瓣膜。Edwards IFU Figure 1。
🌀
Flex Catheter 外層可彎曲導管
通過主動脈弓時提供 co-axiality（與升主動脈軸心共軸）。是會 flex 的那條外管，由 Flex Wheel 控制其末端彎曲程度。
🎈
Balloon Catheter 內層球囊導管
THV 即壓接在這條 balloon 上，deployment 時擴張瓣膜。三個 radiopaque markers（Valve Alignment Markers × 2、Center Marker、Triple Marker）都在此導管上。
🎯
Tapered Nose Cone 錐形鼻錐
最遠端的錐形構造，過 native AV 時導引整條 system 通過鈣化、狹窄的瓣口。
📍
Stylet 內部支撐絲
預置於 guidewire lumen 內。準備時依序：拔出 → flush guidewire lumen → 放回。不放回會傷 lumen，請依 IFU 與 CS 指示。
2Handle 旋鈕詳解（核心）
🎯
Flex Wheel｜彎曲輪
Controls Flex Catheter distal curvature
功能
控制 Flex Catheter 末端的彎曲程度。
目的
讓 delivery system 在主動脈弓變得 co-axial（與升主動脈軸心平行）。
何時轉
tracking 通過弓部時、調整與 annulus 的 co-axiality 時。
驗證
Edwards logo 朝上是 catheter orientation 正確的視覺 hallmark；轉動時隨時用 fluoro 確認。
🧭 方向感提醒：Delivery system 彎曲方向與 flush port 的方向相反。flush port 朝哪邊，catheter tip 就往「另一邊」彎。第一次操作很容易搞錯。請 CS 在台上實機 demo 一次。
🎚️
Fine Adjustment Wheel｜精調輪
Millimeter-level axial adjustment of THV
功能
在 Balloon Lock 鎖住後，讓 THV 沿軸向作毫米級的 aortic ↔ ventricular 微調。
獨特優勢
不需推、拉整條 delivery system，即可把 crimped THV 一毫米一毫米地往 aortic 或 ventricular 側精準微調 — 整條 catheter 在弓部不會跟著動，對 co-axiality 與 stability 是關鍵保護。
何時轉
deployment 前，最後幾毫米的 implant height 微調。
🚨 鐵則：Balloon Lock 沒鎖上時禁止轉 Fine Adjustment Wheel；也禁止把 valve 推過 distal Valve Alignment Marker。
🎯 臨床意義：high-implant / 1–2 mm above annulus 的精準度，就是這顆輪子在做的事。是否要採取 high-implant 策略，需依術前 MDCT、conduction risk、root anatomy 與 proctor 共同決定。
🔒
Balloon Lock｜球囊鎖
Engages inner balloon catheter to outer flex catheter
功能
把 inner Balloon Catheter 鎖到 outer Flex Catheter 上，讓兩者一起動，整條 system 變成「剛體」。
Disengage（開鎖）
alignment 階段把 balloon 從 flex catheter 內拉出來、調整 valve 在 balloon 上的相對位置時。
Engage（鎖上）
要做 fine adjustment 與 deployment 時。鎖上之後 Fine Adjustment Wheel 才能精準地把 valve 上下推。
🔑 設計邏輯：Balloon Lock 把外/內兩條導管「黏」成一體，Fine Adjustment 才有意義 — 否則轉輪只是讓 balloon 在 flex catheter 內滑動。
3Balloon 上的 Radiopaque Markers

Balloon Catheter 上有：定義 balloon 工作長度的 Valve Alignment Markers（兩端各一）、協助瓣膜定位的 Center Marker（中央）、以及位於 balloon 近端用來指示 deployment 時 Flex Catheter 位置的 Triple Marker。Fluoro 上必須清楚分辨這三組 marker 與 Warning Marker。

Marker 位置 Fluoro 上要看什麼
Valve Alignment Markers
（一對）		 Balloon 兩端 THV 必須夾在這兩個 marker 之間。
禁忌 不可超過 distal marker。
Center Marker Balloon 中央 對齊 annular plane（aortic anulus 平面）；採 high-implant 策略時依 proctor 指示對應目標高度。
Triple Marker Balloon 近端外側 Deployment 時 Flex Catheter tip 要對準這裡；抽 system 前也要鎖回這裡。
Warning Marker Balloon catheter 上的警告線 Alignment 時把 balloon 拉出 flex catheter，看到部分 Warning Marker 出現即停，禁忌 不可拉超過 Warning Marker。
4「Alignment」三層次拆解

這是最容易混淆的地方。「Alignment」在 S3 系統至少有三個不同意思，講的時候要明確指出是哪一層次。

1 Valve-to-Balloon Alignment 瓣膜對球囊對位
時機THV 出 sheath 後、進入弓部之前，在血管直線段做。
動作Disengage Balloon Lock → 把 balloon catheter 往後拉 → 把 crimped THV 從 flex catheter 內「拉出來、對到 balloon 中央」 → 看到部分 Warning Marker 即停。
目的讓 THV 正好坐在 balloon 兩個 Valve Alignment Markers 之間。
🚨 鐵則：必須在血管直線段做。在彎曲段做可能造成 delivery system 損壞、無法充氣 balloon。
2 Co-axial Alignment 共軸對位
時機通過 native AV、進入 LVOT 時。
工具Flex Wheel 調 Flex Catheter 的彎曲度。
目的讓 system 與升主動脈、annular plane 都共軸 → 避免歪斜植入。
驗證Edwards logo 朝上、fluoro 顯示 system 與 annular plane 垂直。
3 Fine Height Alignment 高度精調
時機Deployment 前最後一步。
順序Disengage Balloon Lock → 把 Flex Catheter tip 退到 Triple Marker 中央 → re-engage Balloon Lock → 開始用 Fine Adjustment Wheel 精調。
工具Fine Adjustment Wheel。
目的把 Center Marker 對到目標植入高度（aortic ↔ ventricular 微調）。
⚠ Commissural Alignment 不是 S3 Ultra 的內建功能
說明Sapien 3 valve 雖然可在 crimping 時把一個 commissure 對到 3 / 6 / 9 / 12 點鐘方向，但 ALIGN-TAVR 研究顯示這樣做並沒有改善 commissural alignment，推測原因是 delivery catheter 經過主動脈時的彎曲性。
結論Commander delivery system 沒有 commissural alignment 旋鈕。CS 若提到 commissural alignment，可能是在講 crimping orientation 偏好，而非術中可調機制。
補償S3 stent frame 較矮 → coronary re-access 一般較不被 commissural orientation 限制。
5Deployment 心智走訪（名詞對動作的順序感）
📖 使用方式

這是讓你預習名詞對應到動作的順序感，不是 step-by-step 操作指南。實際每一步請依 CS 與 proctor 即時指導。

💉 上場前 Heparin 劑量目標

IFU 明列：給 heparin 維持 ACT ≥ 250 秒。實際劑量、追加時機由麻醉/術者視當下凝血狀態與出血風險決定 — 此為提醒，非劑量處方。

1
Sheath 進入 → THV 出 sheath。⏱ 5 分鐘規則：THV 不可在 sheath 內停留超過 5 分鐘，否則 leaflet 可能受損。
2
血管直線段 → disengage Balloon Lock → 拉出 balloon → 看到部分 Warning Marker → Valve-to-Balloon Alignment（Level 1）。
3
Engage Balloon Lock → 用 Fine Adjustment Wheel 把 THV 對到兩個 Valve Alignment Markers 中間。
4
Tracking 過弓 → Flex Wheel 適度 flex → 過 native AV → 進 LVOT。
5
Co-axial Alignment（Level 2）：Flex Wheel 微調共軸；驗證 Edwards logo 朝上。
6
Disengage Balloon Lock → Flex Catheter tip 退到 Triple Marker 中央 → re-engage Balloon Lock。
7
Fine Height Alignment（Level 3）：Fine Adjustment Wheel 微調到目標高度。
8
確認：THV 在兩個 Valve Alignment Markers 之間 ✓ 、Flex Catheter tip 在 Triple Marker 上 ✓ 、Edwards logo 朝上 ✓。
9
Rapid pacing → SBP < 50 mmHg、stable run → slow controlled inflation → hold 3 sec → deflate → stop pacing。
10
抽出前必須 Unflex：Flex Catheter tip 鎖回 Triple Marker → 退出 sheath。未 unflex 直接抽 = patient injury caution（IFU 明列）。
6Deployment 時的三人指揮模式（Pacing Protocol）

Deployment 那關鍵的 30 秒是三個角色的合作：Primary Operator（主術者）下令、Pacemaker Operator（節律器手）控制脈衝、Secondary Operator（副手 / 送球員）執行 inflation。每一個動作都採「下令 → 對方覆誦 → 動作」的閉環溝通（closed-loop communication），避免在 BP < 50 mmHg 的窗口出現指令誤解。

步驟 🩺 Primary Operator主術者 ⚡ Pacemaker Operator節律器手 🎈 Secondary Operator副手 / 送球員
1 — 節律器備妥 🗣 「Pacemaker Ready」 向團隊宣告已備妥 —
2 確認 THV 已就位 🗣 「Pacemaker Ready」 覆誦確認收到 — —
3 — 啟動 pacing 🗣 「Pacing On」 —
4 同步確認以下 4 項：
  • Sustained 1:1 capture
  • SBP ≤ 50 mmHg
  • Pulse pressure < 10 mmHg
  • THV 位置正確
🗣 「Inflate」 		— —
5 — — 緩慢可控初次充氣 → 完全充飽後 hold 3 秒 → 洩氣 🗣 「Inflating」→「1…2…3…」→「Deflating」 同步口述每一步進度
6 確認 balloon 完全洩氣 🗣 「Pacemaker Off」 — —
7 — 關閉 pacing 🗣 「Pacemaker Off」 覆誦並執行 —
📐 Pacing 設定原則

• 確認血液動力學穩定後再開始 rapid pacing；速率以術前 BAV 時所確認的數值為基準。
• 若未達 sustained 1:1 capture、SBP ≤ 50 mmHg、pulse pressure < 10 mmHg，需調整速率並重新跑一次 pacing 序列。
• 典型 Pacing Range：160 – 220 bpm

🚨 黃金鐵則
  1. Secondary Operator 與 Pacemaker Operator 只能依 Primary Operator 的口令動作 — 沒有 Primary 的明確指令，不自行 inflate、不自行 pace、不自行關 pacer。
  2. 每個指令都要覆誦回去（closed-loop）。BP < 50 mmHg 的窗口很短，誤聽 / 漏聽會讓整個 deployment 失節奏。
7第一例應該主動問 CS 的 5 個問題
  1. Edwards logo 朝上的 reference 在哪個 fluoro view 最好驗證？（防止方向感錯）
  2. Fine Adjustment Wheel 一格大概對應幾 mm？我們今天的 implant target 是 annular plane 上方幾 mm？（量化感覺）
  3. 如果 alignment 出問題、balloon 沒回到 flex catheter 內，retrieval 的標準動作是什麼？（bail-out 預案）
  4. Rapid pacing 的 BP threshold 我們今天用 50 mmHg 還是更低？stable run 要看幾秒？（避免 deployment timing 不一致）
  5. Unflex 之後抽 system 時，如果遇到阻力我先做什麼動作？（IFU 強調 unflex 重要性，但 troubleshooting 要問現場專家）
