護理紀錄書寫基本原則

核心理念：護理紀錄是法律文件，也是臨床溝通的橋樑。好的紀錄應該讓下一班同仁「看完就能接手照護」。

一、FOCUS-DAR 架構

本院護理紀錄採用 FOCUS-DAR 格式：

Focus 焦點 — 病人的主要問題或照護焦點（如：胸痛、心衰竭、術後照護）
D (Data) 資料 — 主觀（病人陳述）+ 客觀（生命徵象、檢驗值、身體評估）
A (Action) 行動 — 護理措施（給藥、通知醫師、處置）
R (Response) 反應 — 病人對措施的反應、效果評值

二、心血管病房書寫要點

  • 生命徵象完整性：BP、HR、RR、SpO2、體溫缺一不可，並記錄測量方式（如：左臂坐姿）
  • 疼痛評估：使用 NRS 0-10 分、記錄疼痛部位、性質、放射、誘發因素
  • 心臟相關評估：水腫程度（pitting edema 0-4+）、每日體重、I/O 量、呼吸困難程度
  • 傷口評估：穿刺部位（groin/radial）、有無血腫 hematoma、滲血 oozing、脈搏檢查
  • 藥物反應：抗凝血劑使用後的出血徵兆觀察、降壓藥物後的血壓變化
  • 心電圖變化：monitor rhythm、有無 arrhythmia、ST 變化

三、書寫禁忌

避免以下情況：
✗ 使用模糊字眼：「還好」「正常」「差不多」→ 應具體描述
✗ 漏記時間點：所有評估與處置應有明確時間
✗ 抄前一班紀錄而不更新數據
✗ 缺少病人反應（只寫 D、A 而漏了 R）
✗ 使用非正式縮寫（如：OK、so so）

衛教

DAPT 用藥衛教

【Focus】DAPT 用藥衛教 【D】 病人為 PCI 術後，目前使用 DAPT：Aspirin 100mg QD + Plavix 75mg QD / Brilinta 90mg BID。 病人/家屬對 DAPT 重要性之理解：不了解 / 部分了解 / 已了解 【A】 衛教內容： 1. 解釋 DAPT 功能：預防支架內血栓形成 2. 強調不可自行停藥，即使拔牙、手術前也需先諮詢心臟科醫師 3. 預計使用期間：6-12 個月 4. 副作用觀察：瘀青、牙齦出血、黑便、血尿 → 回診告知 5. 若漏服，不可加倍補服 6. 隨身攜帶用藥卡，就醫時主動告知 7. 提供書面衛教單張 【R】 病人能複述：「不能自己停藥」「有出血要回診」。 家屬表示會協助提醒服藥。 衛教理解程度評值：良好 / 需再次衛教。

護理長回饋與建議

王欣怡護理師建議：「待改善的護理紀錄希望可以加入病人心靈衛教或指導」——護理紀錄不應只記錄生理層面，也應涵蓋心理支持、靈性照護、情緒評估等全人照護面向。

全人照護紀錄範例

心理/靈性照護紀錄示範：
病人於晨間表示對心導管手術感到焦慮，擔心術後能否恢復日常活動。予以傾聽及同理，向病人說明手術過程及術後復健計畫，鼓勵表達感受。病人表示「聽完比較安心了」。轉介臨床心理師評估，家屬（太太）在旁陪伴給予支持。持續關心病人情緒變化。
（紀錄中缺乏心理評估、情緒狀態、焦慮程度、睡眠品質、病人對疾病的認知與感受等全人照護面向的記載。）
改善建議：心血管病人常伴隨焦慮與憂鬱，紀錄中應包含：(1) 病人情緒狀態（焦慮、害怕、平靜等）(2) 睡眠品質 (3) 疾病認知與自我照顧信心 (4) 護理師的心理支持措施 (5) 是否需要跨團隊照會（臨床心理師、社工師、宗教關懷師）。

護理紀錄自我查核表

每次書寫完畢，請用以下清單自我檢核：

基本要素

  • 是否使用 FOCUS-DAR 格式？（Focus → Data → Action → Response）
  • Data 是否同時包含主觀資料（病人主訴）和客觀資料（VS、Lab）？
  • 生命徵象是否完整？（BP、HR、RR、SpO2、BT）
  • 所有處置是否有明確的時間記錄？
  • Response 部分是否記錄了病人對處置的反應？

心血管專科要素

  • 胸痛是否有 NRS 分數、部位、性質、放射描述？
  • 術後傷口是否評估了穿刺處、末梢循環、脈搏？
  • 心衰竭是否記錄了每日體重、I/O、水腫程度、NYHA？
  • 抗凝血劑使用後是否觀察出血徵兆？
  • ECG/Monitor rhythm 是否有記錄？

品質指標

  • 是否避免使用模糊字眼（OK、正常、還好）？
  • 數據是否為本次評估所得，而非抄錄前一班？
  • 通知醫師是否有記錄醫師姓名及醫囑內容？
  • 衛教是否記錄了衛教對象、內容、及病人回覆示教？
  • 趨勢變化是否有比較（如：較昨日改善/惡化）？

法律層面

  • 所有異常事件是否有「發現時間 → 處置 → 結果」完整記錄？
  • 是否記錄了通知醫師的時間及醫師回覆？
  • 病人拒絕治療是否有記錄並簽名？
  • 約束使用是否有評估理由、核准、定時評估紀錄？
