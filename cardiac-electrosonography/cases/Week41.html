ECG Synthesis：這張 ECG 在說什麼

竇性節律＋短 PR＋QRS 起始平緩上升（delta 波，I、aVL、V4–V6 最明顯）＝ pre-excitation（WPW pattern）。竇性節律時旁道順行傳導 → PR 縮短、心室提早去極化 → delta 波。注意：WPW 的特徵不一定出現在基線 ECG（「concealed」WPW，旁道只能逆行）。旁道使他易發生迴路型快速 SVT。WPW 少數伴隨結構性心臟病 → echo。

Cardiac Electrosonography Synthesis：整合與處置

心悸＋WPW pattern → 很可能有心搏過速發作 → WPW syndrome。最常見是 orthodromic AVRT——有症狀但不致命。少見情況：AF 經旁道下傳 → 極快的寬 QRS 心搏過速 → 可惡化為多形性 VT／VF → 猝死。Mapping 與旁道 ablation 治癒症狀並消除致命風險。

教學重點

  • Delta 波 ＋ 心悸 ＝ 轉電生理，不需等到證實 AVRT。
  • Pre-excited AF 的急救：禁用 adenosine、verapamil、digoxin、β-blocker（阻斷 AV node 反而讓旁道獨佔）；不穩 → 電擊；穩 → procainamide／ibutilide。
  • WPW 的 echo 要看：Ebstein、HCM、其他先天異常。
