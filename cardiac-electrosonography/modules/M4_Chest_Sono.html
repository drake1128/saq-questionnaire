與心臟超音波不同，肺部超音波看到的主要是 artifact——因為空氣幾乎完全反射超音波。當病變取代肺泡內的空氣、或液體聚積在肺周圍時，反而能看到清楚的結構。 本模組整理：肺葉解剖、探頭擺位、正常（lung sliding、A-lines）與異常（B-lines、實質化、積液、氣胸的 lung point）徵象，以及把胸腔超音波納入床邊評估的演算法。

1. 胸腔超音波概論

1.1 基本原理

  • 胸腔超音波發展較晚，因為超音波無法穿過充氣結構。健康肺的肋膜線是邊界，也是反射徵象的產生者。
  • 肺內的異常徵象取決於空氣／液體比例：任何取代肺泡空氣的東西（液體、血、膿）或造成間質增厚的過程都會產生可辨識的變化。
  • 肺水腫、氣胸、肋膜積液、肺塌陷等多數病變都延伸到肺的周邊，所以超音波能區分空氣與其他物質產生的各類 artifact。

1.2 肺葉體表解剖

右肺三葉（RUL、RML、RLL）；左肺兩葉（LUL、LLL）加上類似 RML 的退化第三葉 lingula（超音波不易看到）。

1.3 肺與肋膜檢查

  • 探頭：linear 或 phased array 皆可。Phased array 較佳——同一支可做心臟，且 footprint 小、能塞進肋間，影像較好。高頻 linear（血管用）適合細看肋膜線。
  • 探頭 marker 永遠朝頭側。
  • 建議掃描點：前胸沿鎖骨中線 2 個點（相隔 1–2 個肋間）；側胸沿中腋線與後腋線再 1–2 個點；PLAPS point（posterior and/or lateral alveolar and/or pleural syndrome）在後腋線與第 10–12 肋間的交點——找肋膜積液與實質化最好的位置，PLAPS 病變有助診斷肺炎。對側同法重複。

1.4 探頭擺位：標準切面與 batwing sign

Marker 朝頭側、跨在兩根肋骨之間。標準肺部切面：上方是肋膜線，下方一連串等距的 A-lines，兩側是上、下肋骨各自產生的無回音聲影——整體像一隻蝙蝠飛出螢幕，稱 batwing sign。

2. 正常與異常的肺與肋膜徵象

2.1 Lung sliding

呼吸時臟層肋膜相對壁層肋膜與胸壁滑動，使高回音的肋膜線閃爍（高頻探頭最明顯）。有 lung sliding 強烈提示：兩層肋膜相貼（該處無積液、無氣胸）且病人有在通氣。

Lung sliding 消失的原因

  • 肋膜腔有空氣（氣胸）——超音波無法穿過肋膜空氣
  • 呼吸暫停或通氣不足（對側支氣管插管、支氣管阻塞）
  • 曾做 pleurodesis
  • 大型 bullae
  • 大片緻密的肺實質化
  • Lung pulse：心臟搏動使肋膜線呈脈動樣。
  • Curtain sign：在正常充氣肺的兩側 PLAPS point，吸氣時充氣的肺向下延伸蓋過橫膈與膈下器官（右肝／腎、左脾／腎），暫時遮住，呼氣時再出現。

2.2 A-lines

肋膜線的混響（reverberation）artifact：水平、高回音、彼此與肋膜線等距。不論空氣在肺實質或肋膜腔都會出現。A-lines ＋ lung sliding ＝ 該處肺正常充氣。

2.3 B-lines

從肋膜起始、垂直延伸到螢幕底端的投影；隨 lung sliding 移動、抹去 A-lines。代表小葉間隔增厚和／或肺泡充填。

  • 單一切面 1–2 條可為正常；≥3 條異常。
  • 單一切面有 B-lines → 局部浸潤（如局灶性肺炎）；全面性 B-line pattern → interstitial syndrome，鑑別：肺水腫、多灶性肺炎、ARDS、間質性肺病。

2.4 肺泡實質化（alveolar consolidation）

肺泡被液體、發炎取代或塌陷後，肋膜深處出現有回音的組織，質地像肝臟 → lung hepatization。實質化內的點狀高回音＝sonographic air bronchogram（細支氣管仍有空氣）。

肺炎 vs 肺塌陷

  • Dynamic（會動的）air bronchogram → 空氣仍在細支氣管進出 → 肺炎（高特異性）
  • Static air bronchogram → atelectasis

2.5 肋膜積液

超音波偵測積液容易，且區分液體 vs 實質化的能力遠優於胸部 X 光。積液＝以胸壁、橫膈、肺為邊界的無回音空間，伴隨塌陷肺與橫膈的動態變化。

徵象意義
單純無回音液體Uncomplicated effusion
有分隔（septated）／局限（loculated）Complicated effusion
Jellyfish sign（flapping lung）積液中塌陷肺的擺動
Plankton sign複雜積液中漂浮的回音絲
Hematocrit sign血胸：回音物質依重力分層、越深越亮

3. 臨床應用

3.1 Alveolar-interstitial syndrome（AIS）

間質瀰漫受累、肺泡－微血管交換受損的一群疾病：慢性如肺纖維化，急性如 ARDS。肺部超音波是簡便的床邊工具：瀰漫 B-lines＝肋膜下小葉間隔增厚，呈融合、貫穿全深度、強度不衰減的垂直回音束。

3.2 氣胸

三句話

  1. 探頭位置有 lung sliding → 排除該處氣胸；有 B-lines 也排除（B-lines 在臟層肋膜深處，肋膜有空氣就看不到）。
  2. Lung sliding 消失只是「可能」氣胸。
  3. Lung point 是氣胸的 pathognomonic sign：部分塌陷的肺與氣胸空間的交界——呼吸週期中塌陷肺進出畫面，鄰近的氣胸區域不動。位置有助判斷氣胸範圍與胸管放置位置。

3.3 肺水腫／血管充血

心因性肺水腫最典型是廣泛的 B-line pattern。但 B-lines 不具特異性（只代表該處有空氣以外的東西：液體、感染、發炎…），需要額外線索：

肺水腫／血管充血多灶性肺炎／ARDS
分布雙側、常重力依賴（下肺野更嚴重）不對稱、有正常 A-line 區域（sparing）
肋膜線較薄、平滑增厚（>2 mm）、粗糙不規則
典型組合廣泛雙側 B-lines ＋ 平滑肋膜線 ± 肋膜積液—

4. BLUE protocol 與判讀總表

作者改編常被引用的 BLUE protocol（Lichtenstein 2008）作為臨床使用的架構：

演算法文字版

初步臨床評估 → 疑似肺部病因 → 做肺部超音波 → 先看 lung sliding：

  • Sliding 存在
    • B-line pattern → 肺水腫
    • A-line pattern → 做 DVT 檢查：有 DVT → 肺栓塞；無 DVT → 看 PLAPS：有 → 肺炎；無 → 氣喘或 COPD
  • Sliding 存在或消失、A/B 混合 pattern → 肺炎
  • Sliding 消失
    • B-line pattern → 肺炎
    • A-line pattern：有 lung point → 氣胸；無 lung point → 需要其他胸部影像
肺部超音波 pattern臨床解讀
Lung sliding ＋ A-line pattern正常充氣的肺
Lung sliding 消失 ＋ A-lines ± lung point氣胸
中度 B-lines（可見 4–5 條）小葉間隔病變
瀰漫 B-lines（可見 7–8 條）Alveolar-interstitial syndrome
Lung hepatization ＋ dynamic air bronchogram肺炎
Lung hepatization ± static air bronchogram肺塌陷
無回音液體、無分隔單純肋膜積液
有回音液體、有分隔複雜肋膜積液

重點回顧

帶走的八件事

  1. 肺部超音波看的是 artifact；phased array、marker 朝頭側、跨兩肋之間找 batwing。
  2. 掃描點：前胸 2、側胸 1–2、PLAPS point（後腋線 × 第 10–12 肋間）；兩側都做。
  3. Lung sliding ＋ A-lines ＝ 正常充氣。
  4. Sliding 或 B-lines 任一存在 → 該處排除氣胸；lung point → 確診氣胸。
  5. ≥3 條 B-lines 異常；雙側瀰漫 ＋ 平滑肋膜線 ＋ 重力依賴 → 心因性肺水腫；不對稱 ＋ sparing ＋ 粗厚肋膜線 → 肺炎／ARDS。
  6. Hepatization ＋ dynamic air bronchogram → 肺炎；static → 塌陷。
  7. 積液：無回音無分隔＝單純；分隔／plankton／hematocrit sign＝複雜或血胸。
  8. 喘的病人：肺部超音波 ＋ TTE 一起做，走 模組 1 的呼吸困難 pathway。
