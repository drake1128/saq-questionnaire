MODULE 01

Apical 4 Chamber — 一切的起點

重症床邊心超最先要練會的，就是心尖四腔（A4C）。這一段從手勢開始講：探頭為什麼不能平壓在胸口、心尖在哪、影像上左心室該長什麼樣。

共 1:59

本段重點

  1. 探頭不能垂直平壓在胸口 —— 那個角度取不到心臟的解剖切面。
  2. A4C 之所以叫 Apical，是因為從心尖看進去；先在病人身上摸到心尖，再把探頭朝它對準。
  3. A4C 是資訊量最大的一個 view：一眼看到四個腔室的相對大小與收縮狀況。
  4. 左心室壁比右心室厚，是辨認左右的第一個線索。
  5. 這個動作要練，練到能快速取得，才有臨床價值。
完整逐字稿
MODULE 02

在螢幕上把心尖指出來

很短的一段互動：請學員在影像上指出心尖的位置。認得出心尖，才知道探頭要對哪裡。

共 0:08

本段重點

  1. 先在影像上找到心尖，再回頭對應到病人胸壁上的位置。
  2. 小螢幕上那個白白的就是探頭，把探頭與心尖連成一條線，就是 A4C 的取像方向。
完整逐字稿
MODULE 03

這堂課要很實務

講師對課程定調：不是聽完就算，希望每間醫院都帶一個人回去真的會用。

共 0:08

本段重點

  1. 課程目標是可帶回單位執行，不是概念介紹。
  2. 希望每間醫院都有一位代表能實際操作。
完整逐字稿
MODULE 04

微調 —— 最難教、也最關鍵的一件事

能不能取到影像，差別幾乎都在最後那幾度的微調。這段講師要大家盯著他的右手看。

共 0:47

本段重點

  1. 右手相對胸壁是斜的，不是垂直。
  2. 探頭實際貼在胸壁上的面積大概只有 20%，其餘是懸空的。
  3. 微調沒有捷徑，只能靠反覆的手感累積。
  4. 臨床情境：ICU 病人血壓低、喘、尿量少，把探頭放上去看一下，取到影像傳給心臟科同事，就可能直接得到「心衰竭」的答案。
  5. 你不必會判讀，你只要會取像 —— 取到影像傳出去，就已經改變了病人的處置。
完整逐字稿
MODULE 05

Short Axis — 心臟變成甜甜圈

從長軸慢慢轉過去，左心室在畫面上會變成一個圓圈。認得這個甜甜圈，就認得短軸。

共 0:27

本段重點

  1. 動作要慢；轉快了整個解剖關係就跳掉了。
  2. 把心臟擺橫、再微調，左心室的橫切面就出現 —— 這就是 short axis。
  3. 短軸看的是左心室環狀的心肌，是後面判斷區域性室壁動作的基礎。
完整逐字稿
MODULE 06

Parasternal Long Axis — 和肋骨與肺搶位置

胸骨旁長軸（PLAX）最常見的失敗原因不是手法，是被肋骨和肺擋住。這段用模型示範怎麼閃過去。

共 1:38

本段重點

  1. 初學者常見狀況：探頭位置看起來對，畫面卻什麼都沒有 —— 那是穿過了肺。
  2. 探頭要通過肋間；放太靠中間會被肋骨與胸骨擋住，太外側同樣被擋。
  3. PLAX 可以看到 RV 與 LV 的相對關係。
  4. 模型的價值就在這裡：在極短時間內反覆試錯，練出「怎麼讓肺不要擋在心臟前面」的手感。
  5. 取得影像，就是照顧這個病人的第一步。
完整逐字稿
MODULE 07

掃到的不一定是心臟

模型讓你可以無限制地慢慢摸、慢慢掃。這段示範一個典型誤判：掃到的其實是胃。

共 0:28

本段重點

  1. 學習心超最大的門檻是沒有時間慢慢練；模型解決的正是這件事。
  2. 要能分辨「我現在掃到的不是心臟」 —— 例如胃的結構。
  3. 認錯結構比認不出結構更危險。
完整逐字稿
MODULE 08

看收縮 — 哪一塊沒有在動

取到影像之後要看什麼？先看每一段心肌動的幅度是不是一樣。

共 0:51

本段重點

  1. 同一個 view 裡比較各段心肌：這邊在動、那邊也在動，但幅度明顯不一樣。
  2. 位移距離明顯較大／較小的那一段，就是要注意的地方。
  3. 講師的態度：如果掃了卻選擇不看出來，那不如不要掃 —— 把問題留給下一班，不是重症照護該有的思維。
完整逐字稿
MODULE 09

臨床應用 — 一個 severe AS 如何改變決策

這段是整堂課的臨床高潮：三個 view，就足以攔下一次錯誤的拔管。

共 1:12

本段重點

  1. 加護病房常見情境：肺水腫、肺炎、反覆插拔管的病人。
  2. 依序取得三個關鍵 view —— Apical 4 Chamber、Short Axis、Parasternal Long Axis，看心室、心房、主動脈瓣、二尖瓣。
  3. 收縮功能可以完全正常，但主動脈瓣有嚴重鈣化 —— 這就是 severe AS。
  4. 沒看到它的後果：以為條件都符合就拔管，兩個月內反覆拔、反覆再插，每次都當成肺炎處理。
  5. 看到它的後果：心臟專科醫師會做出不同決定 —— 先不要拔，確認主動脈瓣狹窄程度，轉診處理。
  6. 同一台超音波、同樣三個 view，差別只在有沒有人去看。
完整逐字稿
MODULE 10

手把手 — 從隨便一個切面轉到標準 A4C

全課最長的一段實作。講師一步一步口令：翹高、旋轉、再翹高，直到四個腔室都出現，再依台大標準把左心室擺到畫面右邊。

共 2:45

本段重點

  1. 翹高：探頭尾端抬起來，切面就往深部延伸，腔室會變長。
  2. 原地旋轉：不要移動位置，只轉角度；主動脈瓣會在旁邊轉出來。
  3. 把主動脈瓣「帽子打開」的樣子轉出來，是一個標準的中繼點。
  4. 繼續旋轉 → 右心室出現 → 再把右心房帶出來 → 四腔完整。
  5. 擺位規定：台大標準是左心室放在畫面右邊；若在左邊，把探頭轉 180 度（像轉鉛筆一樣，要用力，跑掉了再轉回來）。
  6. 左心室看起來太短，多半是探頭離心尖不夠近；往下移一點再拉回來。
  7. 講師給學員的話：機器擺在那裡，你玩一個下午，就贏了 —— 心超訓練最難得的就是有機器、有時間、沒有人在旁邊催你。
完整逐字稿
MODULE 11

結語 — 你只要願意當一個 assistant

課程收尾。講師把門檻降到最低：不要求你判讀，只要求你把影像拿到。

共 0:36

本段重點

  1. 不需要你扛任何責任、下任何診斷。
  2. 只要願意當一個 assistant：插電、開機、探頭放上去、錄五秒鐘。
  3. 五秒鐘的影像，就足以讓遠端的專科醫師給出方向。
  4. 這是一個每天都可以練、也應該每天練的動作。
完整逐字稿
