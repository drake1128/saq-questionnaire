**作者：** 謝慕揚 醫師（心血管中心主任 ｜ 教學部副主任 / 台大醫院新竹分院）

## 目標

在現有「心血管精準醫學遺傳性疾病中心 — 規劃手稿整理」單頁網頁中，新增兩塊內容：

1. **給轉介醫師的說明**：什麼條件可以轉、病人可得到什麼、費用、聯合照護模式。
2. **給病人的 SDM（醫病共享決策）分頁**：在此門診得到的服務、它的價值、預計付出的費用。

## 已確認決策（brainstorming）

| 決策 | 結論 |
|---|---|
| 疾病範圍 | **只聚焦心血管遺傳病**（不含癌症/新生兒/其他罕病；那些屬全院 NGS，不在本中心 SDM 範圍） |
| 版面形式 | **頂部加分頁籤 (Tabs)**：① 規劃手稿（現有）② 轉介醫師說明 ③ 病人 SDM |

| 閾值來源標示 | **每條閾值旁附出處**（符合可追溯引用要求） |

## 架構

單一 HTML 檔，純 CSS/JS 分頁（無框架），沿用現有 `#1a3a5c` navy 色系與 `.section` 卡片樣式。

```
banner（共用）
└─ tab nav: [① 規劃手稿] [② 轉介醫師說明] [③ 病人 SDM]
   ├─ Tab ①：現有全部內容（Take Home / OCR / flowchart / gantt / 待決事項）+ mermaid
   ├─ Tab ②：轉介醫師說明（technical tone）
   └─ Tab ③：病人 SDM（plain language）
footer（共用，免責聲明）
```

- 分頁切換：JS 加 `.active` class 切換 `display`。預設顯示 Tab ①。
- Mermaid 需在所有分頁渲染後仍可見；`startOnLoad` 維持，隱藏分頁用 `display:none` 不影響已渲染 SVG。
- 費用資料為**單一資料來源**，Tab ② 放專業版速覽、Tab ③ 放病人白話版，金額一致。

## Tab ② — 轉介醫師說明（給轉介醫師，可用專業術語）

### 1. 一句話定位
本中心收治遺傳性心律與心肌疾病，提供基因評估、家族 cascade 篩檢與聯合照護；轉介醫師保留原主治關係。

### 2. 轉介條件（When to refer）— 依四大領域分組，每條閾值旁附出處

**A. 遺傳性心律疾病 / channelopathy**
- Long QT：靜息 QTc ≥ 480 ms，或 ≥ 460 ms 合併不明原因暈厥（2022 ESC VA guideline；2013 HRS/EHRA/APHRS consensus）
- Brugada：自發或誘發 type 1 ECG pattern（2022 ESC VA guideline）
- CPVT：運動/腎上腺素誘發雙向或多形性 VT（2022 ESC VA guideline）
- 不明原因心室顫動 / aborted SCD、年輕猝死存活者

**B. 心肌病變**
- HCM：不明原因 LV 壁厚 ≥ 15 mm（有家族史者 ≥ 13 mm）（2024 AHA/ACC/… HCM guideline）
- DCM：早發或家族性、合併傳導疾病/惡性心律不整家族史（2023 ESC cardiomyopathy guideline）
- ARVC：符合 2010 Task Force Criteria 或右室病變合併家族史
- LVNC / 限制型心肌病合併家族史

**C. 遺傳性主動脈病變**
- 胸主動脈瘤/剝離 < 60 歲，或主動脈根部/升主動脈擴大，或主動脈剝離（建議基因檢測）（2022 ACC/AHA aortic disease guideline）
- 症候群特徵：Marfan、Loeys-Dietz、血管型 Ehlers-Danlos（vEDS）
- 二葉式主動脈瓣合併主動脈病變、主動脈剝離家族史

**D. 家族性高膽固醇血症（FH）**
- 未治療 LDL-C：成人 ≥ 190 mg/dL、兒童 ≥ 160 mg/dL（Dutch Lipid Clinic Network；2019 ESC/EAS dyslipidaemia）
- 肌腱黃色瘤、早發冠心病（男 < 55 / 女 < 60）家族史

**E. 紅旗 / 家族史（跨領域）**
- 一等親 < 50 歲不明原因猝死
- 家族已知致病性變異 → cascade screening（單點位檢測）

### 3. 病人可得到什麼（Deliverables）
- 表型評估：ECG、超音波、CMR、24h/長程心電圖、運動測試、藥物誘發測試（視需要）
- 遺傳諮詢（檢測前/後）、知情同意、VUS 控管流程
- NGS 檢測（WES/WGS 或標的）委由台大總院基因醫學部執行
- 多專科團隊：心臟科 + 基因諮詢師 + 影像（CMR）+ 個管師 + 心理諮詢
- 風險分層、ICD/治療/運動/生育建議
- 家族 cascade 篩檢、長期追蹤、biobank/registry 選項

### 4. 聯合照護模式（Co-management）「誰做什麼」分工表

| 項目 | 轉介醫師 | 本中心 | 台大總院 |
|---|---|---|---|
| 主治關係 / 一般照護 | ✔ 保留 | 協同 | — |
| 基因評估 / 諮詢 | — | ✔ | 支援 |
| NGS 定序執行 | — | 開單 | ✔ 實驗室 |
| 報告解釋 / VUS 判讀 | 共同 | ✔ | 連動 |
| Cascade 家族篩檢 | 協助通知 | ✔ | — |
| 回轉與長期追蹤 | ✔ 回轉後 | 必要時回診 | — |

（與 NTUH 總院高憲立教授團隊資料連動。）

### 5. 如何轉介 + 費用速覽
- 轉介路徑（院內轉診單 / 院外轉介）
- 檢體：2 管 3 ml EDTA 採血管，委外送總院代檢
- 報告時程：檢體送出後約 8–12 週
- 費用速覽（連到下方共用費用表）

## Tab ③ — 病人 SDM（醫病共享決策，白話）

依 SDM 結構：選項 / 好處 / 風險 / 費用。

1. **這個門診是什麼**：一段白話介紹（為什麼你的醫師建議來、會幫你做什麼）。
2. **你會得到的服務**（圖示式條列）：看診評估 → 遺傳諮詢 → 抽血檢測 → 報告解釋 → 家人篩檢 → 後續追蹤。
3. **它的價值（為什麼值得）**：找出病因、預防猝死/及早治療、保護家人（cascade）、生育規劃、用藥與運動建議。
4. **要一起考慮的點（誠實揭露）**：可能驗不到明確答案、VUS 不確定變異、結果對心理/保險的可能影響、需要時間（8–12 週）。
5. **預計費用**：病人白話版費用表（同一份資料）。
6. **常見問題 FAQ**：3–5 題（要抽血幾管？多久有報告？家人一定要驗嗎？驗不到怎麼辦？健保有給付嗎？）。
